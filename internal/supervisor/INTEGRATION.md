# Registry and supervisor integration

`registry.New(configPath)` loads defaults and discovers agents immediately. An empty path uses `LOLAD_CONFIG` or `~/.config/lolad/config.yaml`; a missing config uses SPEC defaults. `List`, `Get`, `Config`, `ReadAgent`, `WriteRuntime`, and `Reload() (Diff, error)` are available. Reload commits its snapshot only after every discovered runtime validates; missing YAML and instances without runtime are skipped. Slug resolution follows the coordinator's revised contract: explicit runtime.slug (validated and lowercased), then sanitized agent.name, then sanitized directory basename. `SanitizeSlug` handles display names, `Slug` handles a directory basename, and `ResolveSlug` applies precedence. A later duplicate is rejected while the first agent remains registered; `Diff.Rejected`, `Diagnostics()`, and optional `registry.WithEvents(func(core.Event))` surface an error event without renaming. `supervisor.RecordEvent` can persist those diagnostics on the supervisor history and bus.

Construct `supervisor.New(supervisor.Options{...})` with the shared SQLite DB, registry's `List()`, Sessions, a map of harness Launchers, Notifier, Mailer and LaunchOpts containing state directory, binary and URL. A nil DB supports ephemeral tests; production must pass the store DB for durability. The package creates `sup_agents`, `sup_events` and `sup_mail`; desired state, crash budgets, restart intent and mail notification cooldowns survive restart. The optional Clock has `Now` and `After`; nil selects wall time.

Adapt registry reload through `ReloadAgents: func(context.Context) ([]core.Agent,error)` that calls registry.Reload and returns registry.List. The supervisor implements the fleet subset of core.Service, HookSink, OnMail, and Trigger. Compose it with the mail, policy and creation services in the integrator; it intentionally does not implement unrelated Service methods. Registry removal forgets supervision and leaves an existing session running.

Call `Run(ctx)` once, or `Reconcile(ctx)` to drive ticks in tests. Start and Restart set desired state; the next tick performs the operation. Stop sends Escape and two C-c keys immediately, then the tick kills the session after ten seconds. Canceling Run leaves sessions alive and waits for outstanding mail watches to finish canceling. Run records transient reconciliation errors and continues; direct Reconcile returns the first error for tests and callers.

Cron uses robfig/cron's parser and Schedule.Next, evaluated by the injected clock at reconciliation. Mail watches run asynchronously so a slow email server cannot delay lifecycle reconciliation. The MailWatch interface is the only subprocess boundary; its default executes `<dir>/tools/email.sh watch <account>` with a ninety-second timeout, matching the read-only Jugui reference's last-line JSON contract. Overrides must honor context cancellation. Initial polling occurs on the first tick, then at the configured interval (default two minutes).

Webhook triggers create one 0600 token per agent at `<state>/agents/<slug>/webhook.token`. The API must authenticate that token before calling `Trigger(ctx, agent, name, body)`; the supervisor verifies the configured trigger name and sends through Mailer as `lolad`. Token authentication belongs at the API boundary. Send failures and external email headers generate events; external email never becomes agent mail.

Verification: package tests, race tests and go vet cover discovery/diffs/validation, byte-preserving writes against a text copy of Jugui's real lolabot.yaml (LF and CRLF), SQLite persistence, adoption, crash/backoff/failure, lifecycle actions, daily rotation/deadline, hook ordering/TTL, notification retries and caps, wake on mail, Claude Stop-hook cooldown, cron, webhook tokens and trusted/external mail. ExecMailWatch was executed against a temporary real shell script with checked argv; no live agent, tmux server, Claude/Codewhale session or real email account was touched.

Implementation choices beyond SPEC: optional ephemeral DB mode for tests, a registry reload callback for package isolation, Schedule.Next driven by reconciliation instead of cron's wall-clock goroutine, and API-owned webhook authentication. All requested behaviors are implemented; no intentional SPEC omissions. The coordinator's October 25 follow-up overrides the original directory-only slug rule with the precedence above. Pub/sub channels have a bounded buffer of 64 and drop events for slow consumers; persisted Events is the source of history. Notification failures exhaust the four scheduled attempts; successful unread deliveries allow at most three further notification cycles. Stop-hook reminders use their separate two-minute per-message cooldown.
